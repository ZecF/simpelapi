Metode Otorisasi Request

Gunakan salah satu metode pengiriman API Key berikut pada setiap request ke server.

Opsi 1: Header HTTP (Direkomendasikan)

Sertakan kredensial Anda di dalam header request agar tidak terlihat langsung di riwayat URL.

x-api-key: YOUR_API_KEY

Opsi 2: Query Parameter

Cocok untuk pengujian cepat atau integrasi langsung melalui pemanggilan URL sederhana.

?apikey=YOUR_API_KEY
